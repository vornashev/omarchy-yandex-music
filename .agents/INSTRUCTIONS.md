# Обязательные инструкции агенту

> Часть постоянного handoff из [README.md](README.md).

## 2. Жёсткие правила работы агента

1. Перед изменениями выполнить:
   ```bash
   cd ~/Projects/omarchy-yandex-music
   git status --short
   git diff --check
   git diff
   ```
2. В репозитории могут одновременно работать другие агенты. Не откатывать и не перезаписывать незнакомые изменения; сначала изучить их и совместить свою работу.
3. Для точечных правок использовать минимальные замены. Не делать полный rewrite больших QML/Python-файлов без необходимости.
4. Не читать и не публиковать содержимое:
   - `~/.config/omarchy-yandex-music/token.json`;
   - временных прямых URL аудиопотоков;
   - пользовательских коллекций и истории прослушивания.
5. Не добавлять пользовательский кэш коллекций на диск. Коллекции кэшируются только в памяти backend.
6. Не выполнять `git commit`, `git push`, создание/перемещение тегов, GitHub Release или Marketplace submission без явного подтверждения владельца.
7. Релиз и заявка Marketplace — два отдельных действия и требуют отдельных подтверждений.
8. Перед Marketplace submission владелец должен явно подтвердить все пять пунктов актуального официального checklist. Не предполагать подтверждение. Форма: `https://github.com/omacom/omarchy-plugin-marketplace/issues/new?template=submit-plugin.yml`.
9. При работе с Omarchy API/плагинами сверяться с установленной документацией Omarchy; не придумывать hooks/API. Стандартный workflow установки должен оставаться рабочим.
10. После существенной реализации обновлять этот файл: текущую версию, статус, тесты, ограничения и следующие шаги.
