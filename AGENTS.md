# Instructions for coding agents

Before making any change in this repository, read **all** Markdown files in [`.agents/`](.agents/), starting with [`.agents/README.md`](.agents/README.md).

Mandatory first steps:

```bash
cd ~/Projects/omarchy-yandex-music
git status --short
git diff --check
git diff
```

Important: the working tree may contain concurrent changes from other agents. Never discard or overwrite unfamiliar edits. Do not commit, push, tag, publish a GitHub Release, or submit to the Omarchy Marketplace without the repository owner's explicit confirmation.

Primary communication language: Russian. Public documentation and changelog must remain synchronized in Russian and English.
