# История изменений

[English version](CHANGELOG.md)

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.7.4] — 2026-09-03

### Добавлено

- Отображение установленной версии плагина в заголовке настроек
- Автоматические повторы после ограничения запросов с паузами 2, 5 и 10 секунд

### Изменено

- Запросы к API Яндекс Музыки выполняются последовательно для медиатеки, поиска, радио, исполнителей и воспроизведения и больше не создают резких всплесков
- Загруженный при запуске индекс любимых треков повторно используется при открытии «Мне нравится»
- Результаты поиска прокручиваются отдельно, а вкладки и поле поиска остаются на месте

### Исправлено

- Очередь сохраняет позицию прокрутки при ручном выборе и не прокручивается повторно, если следующий или предыдущий трек уже полностью виден
- Снятие отметки «Мне нравится» сразу удаляет трек из открытого списка или запущенной из него очереди и обновляет кэш без повторной загрузки всей коллекции
- Сырой ответ Яндекс Музыки HTTP 429 заменён коротким сообщением с понятным действием
- Открытие «Мне нравится» во время запуска больше не дублирует запрос любимых треков

## [0.7.3] — 2026-09-03

### Добавлено

- Ленивая загрузка списка «Мне нравится» и пользовательских плейлистов страницами по 50 треков
- Кэш коллекций в памяти, мгновенно восстанавливающий ранее загруженные страницы плейлистов
- Подсказка лоадера с текущей операцией, временем ожидания, откликом API и доступностью музыки в регионе

### Изменено

- Метаданные коллекций загружаются пакетами вместо отдельного API-запроса для каждого трека
- Список треков виртуализирован и больше не создаёт сотни QML-элементов одновременно
- Очередь, запущенная из частично загруженной коллекции, дополняется в фоне с сохранением исходного порядка
- Записи кэша коллекций действуют 10 минут; одновременно хранится не более восьми записей по принципу LRU

## [0.7.2] — 2026-09-03

### Добавлено

- Кнопка и горячая клавиша `C` для копирования кода Яндекс Device OAuth
- Краткое визуальное подтверждение после копирования кода авторизации в буфер обмена

## [0.7.1] — 2026-09-03

### Добавлено

- Установка одной командой `omarchy plugin add <url> --enable`
- Автоматическая установка backend, Python-окружения, CLI и пользовательского systemd-сервиса при первом запуске
- Автоматическая синхронизация backend после `omarchy plugin update`
- Превью для Marketplace и галерея скриншотов в документации

### Изменено

- Документация по установке, обновлению и удалению теперь соответствует стандартному процессу Omarchy-плагинов

## [0.7.0] — 2026-09-03

### Добавлено

- Внутренняя страница настроек с компактной кнопкой перехода и возврата
- Постоянные настройки в файле с правами `600`
- Раздельное восстановление очереди, позиции, громкости и воспроизведения
- Лучшее качество аудио и режим экономии трафика
- Воспроизведение по порядку, перемешивание, повтор очереди и повтор трека
- Синхронизация repeat и shuffle через MPRIS
- Настройки настроения, рекомендаций и языка «Моей волны»
- Настраиваемые кнопки, исполнитель, название, обложка, прогресс и ширина плеера в баре
- Квадратная, скруглённая и круглая формы обложки
- Обрезка и плавная прокрутка единой строки `Исполнитель — Название`
- Уведомления о смене трека с временно кэшируемой обложкой
- Контекстные состояния загрузки и карточки ошибок с повтором и скрытием
- Shimmer-skeleton для заголовка очереди, списков, исполнителей, плейлистов, лайков и поиска
- Просмотр исполнителя, «Мне нравится» и плейлистов без прерывания текущего трека

### Изменено

- Выход из аккаунта перенесён в настройки и требует подтверждения
- Каждый исполнитель трека имеет отдельную кликабельную область
- Обложка и информация о треке образуют единую область открытия попапа в баре
- Лоадеры в баре и попапе получили общий круговой дизайн и сохраняют угол вращения
- Очередь и skeleton имеют стабильные размеры, чтобы попап не менял высоту
- Открытие коллекции в медиатеке больше не запускает первый трек автоматически
- Открытие исполнителя больше не заменяет очередь и не прерывает воспроизведение
- Настройки «Моей волны» отправляются в актуальном JSON-формате API

### Исправлено

- Плавное перетаскивание громкости и перемотки
- Динамическое отображение целевой позиции без замены реального времени
- Вертикальное выравнивание и совместная прокрутка текста в баре
- Запуск следующего трека после паузы или остановки
- Перекрытие элементов скроллбаром в настройках
- Изменение высоты попапа при загрузке очереди и результатов поиска
